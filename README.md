# TFG - Credit-Risk-Profiling-via-Explainable-AI-and-Clustering
Trabajo de Fin de Grado que propone una metodología de segmentación supervisada para el análisis del riesgo crediticio. El enfoque combina LightGBM, SHAP, UMAP, DBSCAN y SkopeRules para identificar y caracterizar perfiles de clientes a partir de patrones explicativos, mejorando la interpretabilidad de los modelos de credit scoring.
